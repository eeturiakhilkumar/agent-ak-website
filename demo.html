Embed the Floating Orbit Chatbot

Provide interactive support to your users on agent-ak.com with a beautiful local chat widget. It integrates directly using one lightweight script tag and standard JavaScript event cycles.

Integration Guide

1

Deploy script and assets

Copy the fully compiled script file orbit-chat.js to your production website server. If using Vite, place it in the public/ folder.

2

Include tag on target pages

Place this script block inside the <body> element of your website. It will automatically load the chat launcher and style definitions.

<script src="path/to/orbit-chat.js"></script>
3

Start the Python FastAPI local server

In your backend project directory, activate your CORS-configured server. Expose it on the web via an Ngrok tunnel to receive POST endpoints:

ngrok http 8000
